## Skill files written or changed

**1. `brain/skills/mcp-connector.md`: improved (learned_from: 12)**
The old version had 4 short steps and nothing on security. The new version adds the measured token savings
from job 12 (66,300 → 4,800 → 420 tokens for one article), the URL-secret auth pattern that Claude's
connector form forces, what to test and ship, and gotchas about tool-definition cost and sleeping free hosts.

**2. `brain/skills/secure-public-fetch.md`: new (learned_from: 12)**
A method for any tool that fetches a URL a user gives it: check the address when the connection is made
(not just the URL text), block private and metadata ranges including mapped IPv6, follow redirects by hand,
cap time and size, and a test list. It is split out from the connector skill because it applies to any
fetch tool, not only MCP servers.

Both files link to each other, and to `escalate-one-hop` and `learn-a-skill`, which exist in `brain/INDEX.md`.

## How to use them
- A future job that builds a connector or any URL-fetching tool reads `mcp-connector.md` first, then
  `secure-public-fetch.md` for the fetch code.
- `brain/INDEX.md` and `brain/brain.json` are regenerated by `scripts/brain.py` after the job. I did not edit them.
- To check the links, run `python3 scripts/brain.py --check`. I didn't run it because the tool call needed
  approval in this unattended run. The `related` slugs were checked by hand against the file list.
