## How
1. Give a Markdown table (Category, Group, Planned, Actual, Difference) with example amounts clearly marked as placeholders.
2. Add the same data as CSV so it pastes straight into a spreadsheet.
3. Include totals and one or two simple rules of thumb (e.g. 50/30/20).
4. If the owner wants to use it on a phone every day, it is really an app: see static-job-page.
